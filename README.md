## 📌Sobre o projeto

Desenvolvimento de um portfólio profissional com o objetivo de apresentar meu perfil, as tecnologias que estou estudando e os projetos desenvolvidos durante minha jornada na área de Desenvolvimento de Sistemas.

## 🛠️ Tecnologias utilizadas

HTML5: estruturação dos elementos e conteúdos da página.

Bootstrap 5.3.3: utilização de componentes prontos, sistema de grid e recursos para responsividade.

Visual Studio Code: ambiente utilizado para desenvolvimento do projeto.

GitHub: plataforma para armazenamento e compartilhamento do código.

## ⚙️ Funcionamento do projeto

O portfólio é uma página web organizada em seções que permitem ao visitante conhecer minhas informações profissionais e acadêmicas.

Sua estrutura é composta por:

Menu de navegação: permite acessar diretamente as seções Perfil, Projetos e Contato.

Carrossel: apresenta imagens em destaque, com navegação entre os slides.

Perfil profissional: apresenta minha identificação, formação, área de interesse e objetivo profissional.

Tecnologias e ferramentas: exibe as principais tecnologias e ferramentas estudadas, acompanhadas de seus respectivos ícones.

Projetos: projetos com a descrição dos trabalhos desenvolvidos e links.

Contato: disponibiliza acesso ao e-mail, GitHub e LinkedIn.

O Bootstrap é utilizado para desenvolver o portifólio, facilitar a construção do layout e adaptar a apresentação a diferentes tamanhos de tela.
